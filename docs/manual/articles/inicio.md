## Manual operativo de Grimorio

Elige la tarea que necesitas realizar. La navegación y el buscador muestran las
guías permitidas para tu sesión; leerlas no concede permisos para operar.
Algunos enlaces de esta portada pueden no estar disponibles para tu usuario.

## Antes de empezar

Comprueba tu usuario, sucursal y entorno. No prestes credenciales ni pruebes
operaciones con datos reales sin autorización. Los ejemplos del manual son
ilustrativos; las capturas de inventario usan datos ficticios.

**Contar no ajusta existencias.** Una compra, producción o movimiento sí puede
cambiarlas. **Corregir medios de pago no modifica el XML ni el RIDE existentes.**

## Alcance y aceptación

Esta es una primera base operativa centralizada, contrastada con las pantallas
y referencias del repositorio. La navegación se ha probado con usuarios en
desarrollo; eso no certifica cada operación en dispositivos reales o producción.
Cada guía indica su alcance de revisión y sus límites.

Instalación Android, cámara, audio, integraciones externas y procedimientos de
cada equipo deben aceptarse con sus responsables antes de distribuirlos.
Brasa sigue siendo desarrollo; el flujo de canje de premios y el asistente de
IVA temporal no se presentan como funcionalidades terminadas.

La documentación técnica, accesos de servidor, secretos e historial de diseño
no forman parte del buscador operativo. Modificar una guía o subir Git no
despliega el VPS. La ayuda continúa deshabilitada por defecto en producción.

# Modulo Mobile

Aplicaciones Android internas de Grimorio. Los procedimientos de uso se
mantienen en el manual central; los README de cada app conservan compilación,
firma, publicación y verificaciones técnicas.

## Objetivo

Apps actuales: `waitstaff_app` (meseros), `station_app` (estaciones), `attendance_app` (asistencia) e `inventory_app` (conteos con PIN y revisión en ERP). Cada carpeta tiene su README.

Permitir crecimiento por apps moviles sin mezclar codigo con backend o frontend web.

## Regla de documentacion

Cuando se inicie una app movil, crear un README propio dentro de su carpeta con:

- stack tecnologico,
- comandos de build/run,
- convenciones de estructura,
- integracion con backend.
